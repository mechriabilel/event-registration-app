# Event Registration CLI Application

Software Engineering Project - Checkpoint 1 & Checkpoint 2

## Domain Concept Map
- **Attendee**: Represents participants registering for events.
- **Event**: Represents an event with a maximum capacity.
- **Registration**: Link between an Attendee and an Event.
- **Capacity Constraint**: Prevents registration if max capacity is reached.

## Features
- Manage Events (add, list, update, remove, search places)
- Manage Registrations (create, list, change, cancel)
- Data Persistence using JSON file (`events_data.json`)
